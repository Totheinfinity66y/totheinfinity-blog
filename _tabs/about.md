# Hello World! 🌍

Welcome to my personal blog powered by **Jekyll** and **GitHub Pages**.

This blog is built with the [Chirpy](https://github.com/cotes2020/jekyll-theme-chirpy) theme, featuring:

- 🌙 **Dark/Light Mode** — toggle on the bottom left sidebar
- 🔍 **Built-in Search** — full-text search across all posts
- 📑 **Auto-generated TOC** — table of contents for every post
- 🏷️ **Tags & Categories** — organized post management
- 📱 **PWA Support** — installable as a web app
- ⚡ **Fast & Responsive** — optimized for all devices

Stay tuned for more content!
